# MirthState

Automates database schema migration for PostgreSQL and MySQL databases in a single operation.

With MirthState, you get a lightweight tool that stays out of your way.

**What you get**

- Automates database schema migration for
- PostgreSQL and MySQL databases in
- a single operation

## Key Features

- Automates database schema migration for
- PostgreSQL and MySQL databases in
- a single operation

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/MirthState.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
